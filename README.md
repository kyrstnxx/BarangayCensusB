# Barangay Census Portal
## Activity 5 : Simple CRUD

A full-stack web application built with **ASP.NET Core MVC** and **Entity Framework Core** for managing barangay resident records.

## Features
- Admin-only authentication using ASP.NET Core Identity
- Full CRUD operations for resident records
- Dashboard with real-time statistics (total residents, voters, seniors, PWDs)
- Green and white color scheme

## Tech Stack
- ASP.NET Core MVC (.NET 9)
- Entity Framework Core
- SQL Server (LocalDB)
- Bootstrap 5
- C#
